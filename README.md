# DevOps Lab

A small practical DevOps learning environment built on Kali Linux.

## Technologies

- Linux
- Git
- GitHub
- Docker
- PostgreSQL
- Terraform
- Ansible
- GitHub Actions
- Kubernetes

## Lab Objective

Build a small end-to-end application and automate:

1. Application development
2. Containerization
3. Infrastructure provisioning
4. Configuration management
5. CI/CD
6. Kubernetes deployment

## Environment

OS: Kali Linux
Purpose: DevOps Training Lab
